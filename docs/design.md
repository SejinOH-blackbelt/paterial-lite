# PATERIAL Lite 開発設計図（Claude Code版）

Nov 25, 2026 ・ @Sejin Oh

## このドキュメントの使い方

これは、プログラミング未経験の個人が Claude Code だけで「PATERIAL Lite」を完成させるための設計図です。コードは書かず、上から順に Claude Code へ指示を渡していけば形になるように作っています。

- **ゴール**：スマホのブラウザで遊べる、5分のハニワ・スパイ・リズムゲーム（1人 + Bot 5体）を公開すること。
- **進め方**：「開発ステップ」の M0 から順に進めます。1ステップ終わるごとに、実際に遊んで確かめます。
- **困ったとき**：この設計図をそのまま Claude Code に読ませて「今どこまでできている？次は何をすればいい？」と聞けばOKです。
- **壮大版との関係**：本番版の全体設計図は [docs/vision.md](vision.md) にあります。Lite は本番の「スパイ的な侵略」の1場面を切り出したもので、国づくり・クラフト・外交は入れず、「スパイを見破る／見破られない」の面白さだけを先に確かめます。
- **場面の設定**：バイキングの国が、和の国へ代表パテを送り込んだ場面です。採取場は和の国の一区画、市民と市民Botは和の国の住民（オンライン版では守りに来たフレンドが入ることもある）、スパイはバイキングから送り込まれた代表パテです。

## 作るもの

6体のハニワ「パテ」が、和の国の仕事（ミッション）を手分けしてこなすゲームです。その中に1体だけ「塗り替えスパイ」が紛れていて、仕事をするふりをしながら、名物をスキャンしたり、仲間を置物にしたりします。置物を見つけたら「呼び出し」で会議を開き、スタンプと投票でスパイを当てます。1試合約5分。プレイヤーは1人で、残り5体はBotが動かします。

（作りながら変更：最初は「採取90秒×3ラウンド＋会議」だったが、市民役にもやることがはっきりあって、手軽に遊べるように「全員でミッション＋呼び出しで会議」に変えた）

| | シンプル版に入れる | 壮大版まで取っておく |
|---|---|---|
| 遊び方 | ミッション（リズム採取・素材の加工）、スパイのスキャンとイタズラ、呼び出しと会議、スタンプ投票 | 国づくり、クラフト、同盟と裏切り |
| 人数 | 1人 + Bot 5体 | オンライン4〜8人 |
| 国 | 和（茶色の素焼き）とバイキング（グレーの石）の2つ | 6〜8国と相性システム |
| マップ | 和の国の採取場 1枚（画面より広く、カメラが追う。素材ポイント・加工の施設・名物） | 山・川・海、各国の街 |
| 画面 | スマホ縦持ち、ブラウザで動く | アプリストア配信、PCクロスプレイ |
| キャラ | パテ、パーツは頭に刺す1種類だけ | パーツ着せ替え、ポイント交換 |

**「完成」の基準**は3つです。

1. 友達にURLを送るだけで、説明なしに1試合遊べる。
2. 市民役でもスパイ役でも、「もう1回」と思える。
3. パテを叩くと「ポコッ」と鳴って気持ちいい。

## ゲームルール

数値はすべて仮で、遊びながら調整します。

### 勝敗

| 結果 | 条件 |
|---|---|
| 市民の勝ち | みんなでミッションを進めて「国の仕事ゲージ」を満タンにする。または、会議でスパイを当てる |
| スパイの勝ち | 名物を全部スキャンし、さらに自分のミッションも全部終える。または、置物にされずに動ける市民の数をスパイの数と同じまで減らす（いまはスパイ1体なので、動ける市民が残り1体になったとき）。または、王様の支持度が0になって市民がストライキを起こす。または、時間切れ（仮：5分）までに市民がゲージを満たせない |

### 王様パテと支持度

- プレイヤーが市民側のとき、プレイヤーは和の国の **王様パテ** です。人間ではなく、王冠をかぶったパテです（全員が同じ形のパテなので、スパイが紛れ込める）。王様も自分で歩いて、採取やミッションをします。
- プレイヤーがスパイのときは、市民Botの1体が王様パテになります。
- **支持度**：国の住民が王様を信じている度合い（最初は100）。会議でぬれぎぬ（スパイでない市民を調べた）になると、大きく下がります（仮：1回で -50）。画面の上にいつも出ています。
- **ストライキ**：支持度が0になると、市民パテたちが仕事をやめて座り込み、プラカードを掲げます。その時点でスパイの勝ちです。暴動のような暴力表現にはせず、ポップに見せます。
- スパイから見ると、会議で市民に疑いを向けさせて、ぬれぎぬを2回起こさせるのも勝ち筋になります。

### エレメント（見た目だけ）

- パテは1体ずつエレメント（火・水・土・風・雷）を持ちます。デザインは docs/concept/element-pates.png（完成イメージ）と element-parts.png（パーツ分け）。
  - 火：上がオレンジ・下が焦げ茶の溶岩の体、頭に炎、まわりに火の粉
  - 水：水色〜エメラルドの透明感のある体、頭に波しぶき、体の下に渦巻き・まわりに水滴
  - 土：素焼きの茶色の体、頭に草木とピンクの花、体に苔と小石
  - 風：白〜薄い水色グレーの雲の体、頭にたなびく雲、胴に巻きつく風のリングと舞う葉っぱ
  - 雷：濃い紺色の体、頭にギザギザの稲妻、体を走る稲妻とまわりのスパーク
- 形（しずく型・無表情）は全員同じ。腕と足は、その体のいちばん濃い色。
- 重ね順：後ろの飾り → 足・腕 → 体 → 顔 → 体の前の飾り → 頭の飾り → 見分け用の頭のパーツ（花・笠・旗など）。
- 置物になると、エレメントの絵は消えて土の置物になります。
- Lite では見た目だけで、遊び方は変わりません。本番のエレメント（docs/vision.md）の雰囲気を伝えるためです。


### 試合の流れ

1. **役の発表（5秒）**：プレイヤーは「市民」か「スパイ」のどちらかをランダムで引きます。スパイは6体中1体だけです。
2. **ミッションタイム**：全員が採取場を歩き回り、自分に割り当てられたミッションをこなします。スパイはミッションをするふりをしながら、スキャンとイタズラをします。
3. **呼び出し**：置物を見つけた人、または土の祠の鈴で緊急の呼び出しをした人がいると、全員が鳥居の前に集まって会議になります。
4. **会議（30秒）**：スタンプで話し合い、怪しいパテに投票します。
5. 決着がつかなければ 2 に戻ります。勝敗の条件を満たした時点で試合終了です。

### ミッション（市民）

- 1体ごとに4つのミッションが割り当てられます（全員同じ）：①窯で焼く ②製造所で組み立てる ③鋳造所で流し込む ④土のお祈り。全員のミッションの進み具合が「国の仕事ゲージ」にたまります（集めた素材1個ごとに少し、加工やお祈りを終えるとさらに多く。数値は config.ts の MISSIONS と MISSION_WEIGHT）。
- **採取**：素材ポイントでリズム採取をして、加工に必要な素材を集めます（仮：粘土8個・木材7個・鉱石6個）。
- **加工**：集めた素材を施設へ運び、施設のそばで「アクション」ボタンを押すとミニゲームが始まります。できあがると、その素材を使います。時間制限はなく、まちがえてもやり直せます。スティックで動けば、いつでもやめられます。
  - **窯**：粘土を焼く。まねっこ太鼓（光って鳴る順番どおりに太鼓を叩く）
  - **鋳造所**：鉱石を流し込む。杭むすび（赤・青・黄の杭が2本ずつあり、同じ色どうしを線で結ぶ）
  - **製造所**：木材を組み立てる。かんたんなジグソーパズル
- **お祈り**：お祈りする場所で「土のお祈り」をします。**建物の外観は国ごとの雰囲気**（和の国は神社風）ですが、**中に入るとどの国も同じ「土の祠（つちのほこら）」** があり、お祈りの作法も **すべての国で共通** です（どの国のパテも同じ土から生まれたハニワなので、みんな土にお祈りする、というハニワの世界の設定。現実の宗教の作法は使わない）。
  - 土のお祈り（仮）：①鈴を鳴らす（タップ）→ ②手を合わせる（長押し）→ ③拍に合わせて拍手2回（タップ・タップ）→ ④もう一度鈴を鳴らす。拍手する拍は手を合わせ終えたときに決まり、外から縮んでくる輪が手の輪に重なった瞬間に叩く（いつ叩くかが前もって分かる）。叩きそびれたら、まちがいにせず少し先の拍で決め直す。
  - 正しくできたときの音はスパイも市民も同じ。**間違えると、市民は「ブッブー」、スパイは石がこすれるような低い「ゴリッ」**（仮）が鳴ります。スパイの音は小さく、近くにいる人に「なんとなく」聞こえる程度にします。
  - 失敗しても、パテが転ぶような笑いにはせず、やり直せば済む程度のやさしい演出にします。
- **操作**：画面の下のスティックを倒した方向へ進みます（大きく倒すほど速い。パソコンは矢印キー・WASD で8方向）。右下にボタンを出しておき、押せるときだけ光らせます：素材ポイントのそばで「採取」、施設のそばで「アクション」（加工・お祈り）、置物のそばや土の祠で「呼び出し」。スパイは左に「スキャン」「イタズラ」も出ます。光っていないボタンを押すと、押せない理由（素材が足りない、ほかのパテが採取中など）を出します。視界は丸いまま（背中側も見える）。（作りながら変更：最初は十字ボタンの「前進・後ずさり・その場で回る」だったが、まっすぐ進みにくく操作しづらかったのでスティックに変えた。また、止まると自動で始まる形だと、通りがかっただけで始まったり、遠くのパテの予約で「じゅんばん待ち」になったりしたので、ボタンを押して始める形に変えた）

### リズム採取

- 採取中は画面の真ん中に大きな「採取」ボタンが出て、そのまわりの円形メーターを針が回ります。針が円の上の「ちょうどいいゾーン」にあるときにタップします。針がゾーンの真ん中を通る瞬間は、BGMの拍にそろえます。右下の「採取」ボタンで叩いてもかまいません。「Excellent」で素材2個、「Good」で1個、「Bad」（外れ）は0個です。判定ごとに音も変わります（Excellent は明るいチャイム付き、Bad はこもった音）。
- **素材ごとの難しさ**：粘土はゆっくりめでゾーンが広い（やさしい）。木材（竹）はゾーンがせまい。鉱石（石）は針が速め。
- **針の速さはタップごとに変わる**：1回タップするたびに、次の1周の速さが素材ごとの候補の中から変わります（速くなったり遅くなったり）。それでも針がゾーンの真ん中を通る瞬間は、拍か半拍にそろえます。判定はタップした瞬間の針の角度で決めます。（数値は config.ts の METER）
- **Bad でも素材は減る**：1回叩くと、Excellent は2個・Good は1個・Bad も1個、ポイントの残りが減ります。雑に叩くと素材が無駄になります。（数値は config.ts の STOCK.cost）
- **素材はなくなる**：素材ポイントごとに残りの量があり（仮：粘土12・木材10・鉱石8）、空になると採取が終わり、15秒たつと元に戻ります。空のあいだは素材の絵が灰色で薄くなり、「からっぽ ○秒」と元に戻るまでの秒数が出ます。
- **取り合い**：1つの素材ポイントで採取できるのは1体まで。先に採取を始めたほうが使います（向かっている途中の「予約」では取られない）。ほかのパテが採取中なら「採取」ボタンは光りません。Botは使用中なら、そばで順番を待ちます。
- **採取をやめる**：採取中にスティックを倒すと、採取をやめて動き出します。
- **採取中はまわりが見えにくい**：採取（やミッション）のあいだは画面が暗くなり、メーターとボタンが真ん中に大きく出ます。夢中になっているほど背後が無防備になり、スパイにイタズラされやすくなります。

### スパイ（バイキングのパテ、茶色に塗り替え済み）

- **ミッション**：スパイにもミッションが割り当てられます。国の仕事ゲージにはたまりませんが（ほかの人には分からない）、**自分のミッションを全部終えないと、スキャンでは勝てません**。スキャンだけに集中できないので、市民と同じように動き回る必要があります。
- **スキャン**：名物のそばで「スキャン」を押すと、ミニゲームが始まります（クイズ か まねっこ のどちらかがランダム）。成功すると、その名物の設計図のカケラを獲得します。名物を全部（3つ）スキャンし、自分のミッションも全部終えたらスパイの勝ちです。
  - **クイズ**：その国の状態から自動で作る3問（名産・どこの国か・叩く音・国の仕事ゲージがいまどのくらいか・名物の名前）。全問正解で成功。1問6秒。
  - **まねっこ**：名物の4か所が音と一緒に順番に光るので、同じ順にタップ。
  - **失敗**：1回でも間違える・時間切れになると、名物が「ブブー」と鳴り（近くにいれば聞こえる）、その名物はしばらく（仮：60秒）スキャンできません。
  - スパイBot は3秒でスキャンし、ときどき（仮：15%）失敗します。
- **イタズラ「置物にする」**：近くのパテ1体を、ホコリをかぶった「土の置物」にします。一度使うと、しばらく（仮：30秒）使えません。試合が始まってすぐ（仮：20秒）も使えません。動ける市民の数がスパイの数と同じになったらスパイの勝ちです。
- **目撃される**：イタズラの瞬間、近くにいたパテ（仮：半径120ピクセル）には見られます。見た住民Botはスパイへの「疑い度」が大きく上がり、すぐ呼び出しをすることもあります。プレイヤーが市民のときは、目撃したことが画面に出ます。
- **塗りが剥がれる**：変装の塗りは時間とともに剥がれ、塗りムラが大きくなります。様子見で時間を使うほど、バレやすくなります。

### 置物と土の精

- 置物にされたパテは、その試合が終わるまで置物のままです。置物の見た目は、手足のない丸いドーム型のハニワ（ロゴのパテと同じ形）で、その場に残ります（ほかのパテが見つけられる）。
- 置物にされたプレイヤーは **「土の精」** になり、自由に動き回って様子を見られます。ほかのパテからは見えません。ミッションの手伝い、呼び出し、投票はできません（犯人を知っていても伝えられない）。

### 見える範囲

- 画面全体は見えず、自分のパテのまわり（仮：半径130ピクセル）だけが見えます。遠くのパテ、スキャンの光、イタズラの瞬間、置物は、近くにいないと見えません。
- 採取場は画面より広く（仮：画面の約2倍×2倍）、カメラが自分のパテを追いかけます。同じ素材のポイントは2か所ずつ置きます。
- 見える範囲の外は、地面や建物はうっすら見えますが、ほかのパテ（置物も）はまったく見えません。どこに誰がいるかは、近づかないと分かりません。

### 呼び出しと会議

- **呼び出し**：置物のそばに行くと「呼び出し」ボタンが出ます。また、土の祠の鈴を鳴らすと「緊急の呼び出し」を試合中1回だけ使えます（音や塗りムラで怪しいと思ったとき用）。
- **会議（30秒）**：全員が鳥居の前に集まります。文字チャットはなし。「あやしい！」「ちがうよ」「みてた！」の3つのスタンプだけを使います。パテを選んでから「あやしい！」「みてた！」を押すと、その相手を指させます。指さされた相手は、ほかのパテ（Bot）からも少し怪しまれます（「みてた！」のほうが強く効く）。各自のミッションの完了数が並びます（スパイはふりの分も数に入るので、見た目では分からない）。
- **投票**：各自が1体に投票するか、投票しない（スキップ）を選びます。最多票のパテが「調べられる」対象になります。同票やスキップが最多なら誰も調べられません。選んでいるパテには、上からスポットライトが当たり、四すみの枠と矢印で囲まれます（ほかのパテは少し暗くなる）。「投票する」ボタンには「○○に投票」と相手の名前が出ます。
- **発言の記録欄**：文字チャットはなしのまま、押されたスタンプが「笠：みてた！→若葉（地図に印）」のように記録欄に流れて残ります（新しい3行）。
- **指さしの矢印**：「あやしい！」（朱）「みてた！」（藍）で相手を指さすと、言ったパテから相手へ矢印が少しのあいだ出ます。
- **どこで見かけたか**：輪の真ん中に採取場の小さな地図があります。パテを選んで「あやしい！」「みてた！」を押すと大きな地図が開き、見かけた場所をタップすると印（ピン）が置かれます（場所なしでも言える）。小さな地図をタップすると、大きな地図で印を見られます。置物の場所も地図に出ます。Botは、いちばん強く怪しんだ出来事（イタズラを見た場所など）を覚えていて、その場所に印を置きます。
- **結果発表**：①開票：1票ずつ、投票したパテから相手へ票が飛んでいき、数が増えます。②いちばん票が多いパテにスポットライトが当たり、「○○は……」でドラムロール。③正体を発表します（スパイなら紙吹雪と、体に塗りムラが浮かんで跳ねる。ぬれぎぬなら「ズコー」と震えてしょんぼり。だれも調べられなければ「スパイは まだ どこかに…」）。
- 調べられたのがスパイなら、クラッカーと「てへぺろ」の演出で市民の勝ちです。スパイは強制送還され、集めた素材の一部（仮：半分）を**罰金**として没収されます（docs/vision.md のスパイ的な侵略と同じ）。
- 市民が調べられた場合は「ぬれぎぬ！」です。その市民に投票したパテが、それぞれ自分の素材からお詫びの素材（仮：3個ずつ）を**賠償**として渡します。追放はせず、ミッションタイムに戻ります。

### スパイを見破る手がかり

| 手がかり | 見え方 | 気づきやすさ |
|---|---|---|
| 塗りムラ | 体のどこか1か所だけ、元のグレーが小さく見えている | 近づかないと見えない |
| 音の違い | 叩いたときの音が、素焼きの「ポコッ」ではなく石の「コツッ」 | 採取中、近くにいると聞こえる |
| ミッションの失敗の音 | お祈りなどを間違えたとき、市民は「ブッブー」、スパイは低い「ゴリッ」 | スパイの音は小さいので、すぐ近くでないと聞き分けにくい |
| スキャンの光・失敗の音 | スキャン完了の瞬間に名物が光る。失敗すると「ブブー」 | 近くにいれば見える・聞こえる |
| イタズラの目撃 | 置物にする瞬間を見る | 近くにいたときだけ |
| 動き方 | ミッションの場所ではなく名物のまわりをうろうろしている | よく見ていれば分かる |

### Botの動き

- **市民Bot**：自分のミッションをこなします（採取、施設での加工）。置物を見つけたら呼び出します。リズムの精度は個体ごとに少しずつ違います。
- **スパイBot**（プレイヤーが市民のとき）：ミッションのふりとスキャンを混ぜて動き、誰かに見られていそうなときはスキャンを控え、目撃者がいないときだけイタズラをします。
- **投票するBot**：各Botが「疑い度」を持ちます。イタズラを目撃した、スキャンの光や失敗の音を近くで見聞きした、近くで塗りムラや「コツッ」を見聞きした、で上がり、最も疑い度が高い相手に投票します。

### 遊びながら確かめること

- スパイが置物をどんどん作れると、市民がすぐ減ってしまいます。イタズラの待ち時間で調整します。
- 置物にされたプレイヤーは土の精として見ているだけになります。退屈なら、土の精でもできること（スタンプなど）を足すか考えます。

## 画面構成

画面は5つだけで、すべてスマホ縦持ち・片手操作を前提にします。

| 画面 | 表示するもの | 操作 |
|---|---|---|
| タイトル | ロゴ、跳ねるパテ、「あそぶ」ボタン、「あそびかた」ボタン | タップで開始 |
| 役の発表 | 「きみは市民」または「きみはスパイ」、目標を1行で | 自動で次へ |
| 採取場 | マップ、パテ6体、素材ポイント、施設、名物3つ、国の仕事ゲージ、自分のミッション、残り時間、採取のメーター | タッチで移動、タップで採取、呼び出し、スパイはスキャンとイタズラのボタン |
| 会議 | パテ6体が輪になって並ぶ、各自のミッション完了数、スタンプ3種、残り時間 | パテをタップして投票、スキップ、スタンプを押す |
| リザルト | 勝敗、スパイの正体、スパイがいつどこでスキャン・イタズラしたかの振り返り、「もう1回」ボタン | タップで再戦 |

リザルトの「振り返り」は大事です。「あのとき光ったのはそれか！」と分かることが、次の1試合を遊びたくなる理由になります。

## アートとサウンド

絵はドット絵で統一します。パテは丸っこい形と空洞の目・口だけで成立するので、小さなドット絵と相性が良く、1人でも描ききれる量に収まります。

（作りながら変更：Codex がプログラムで描いた**絵本風**の絵が育ったので、ドット絵はやめて絵本風で仕上げる。全体の枠・ボタン・タイトルは**洋風の絵本**。マップの絵はその国の文化に合わせる：和の国は**和風の絵本**、中華の国なら中華風、米国系ならアメコミ風。Lite のマップは和の国だけなので、採取場は和風の絵本にする。採取場は一度**水墨画**にしたあと、使い手の参考画像をもとに**浮世絵風**にした（山吹色の砂地と茶のにじみ、上に朱の夕空と藍の遠山、下の両隅に北斎の大波、左右に渦巻く雲・松・竹・梅・藍の岩。太い墨の輪郭と平らな色面）。参考画像の大きな家は、施設とまぎらわしいので描かない。下の「ドット絵の決まり」は昔の案として残す）

### ドット絵の決まり

- **パテの大きさ**：32×32ドット。画面では3〜4倍に拡大して表示します。
- **色数**：全体で16色前後に絞ります。和は素焼きの茶色、バイキングは石のグレーを基調にします。
- **顔**：眉毛なし、目と口は黒い穴。表情は変えず、動きで感情を出します。
- **塗りムラ**：スパイだけ、体のどこかに2×2ドットのグレーが残ります。位置は試合ごとに変わります。

### 必要な絵の一覧

| 絵 | 枚数の目安 | メモ |
|---|---|---|
| パテ（立ち・歩き・跳ねる・じっとする） | 8〜10コマ | 茶色で1セット描き、グレーは色違いで作る |
| 頭のパーツ（見分け用） | 6種 | 花、笠、角、旗など。「ブスッと刺さっている」感じに |
| 素材ポイント（粘土の山、木材＝竹、鉱石＝石） | 3種 | 採取中に揺れる2コマ |
| 名物（からくり歯車の櫓、茶釜、鳥居） | 3種 | 光るコマを1つずつ |
| 地面タイルと飾り | 10種ほど | 土、草、石畳、灌木 |
| スタンプ、ボタン、ロゴ | 10種ほど | 文字は太く読みやすく |

最初は Claude Code に「仮の絵」をプログラムで描かせて進め、ゲームが面白いと分かってから本番のドット絵に差し替えます。ドット絵を自分で描くなら、無料でブラウザから使える Piskel が始めやすいです。

### サウンド

- **BGM**：テンポはゆったりめ（仮：1分間に100拍）。打楽器と木琴中心の、とぼけた曲をループさせます。（決定：Codex がプログラムで作る。採取の判定と同じ「音の時計」と同じ0拍目で鳴らし、拍がずれないようにする）
- **叩く音**：素焼きは「ポコッ」、石は「コツッ」。この違いがそのまま推理の手がかりになります。
- **演出音**：スキャン完了の「ピロン」、投票の「ポン」、正解のクラッカー、はずれの「ズコー」。
- 最初は効果音も Claude Code にプログラムで合成させます。素材を使う場合は、商用利用できるフリー素材かどうか、利用規約を必ず確認します。

## 技術の選び方

ブラウザで動く2Dゲームとして作ります。Unityなどのゲームエンジンはマウスで画面を操作する作業が多く、未経験者が Claude Code に任せきれません。ブラウザ向けなら全部が文字のファイルなので、Claude Code が最初から最後まで作れます。

| 使うもの | 役割 | 選んだ理由 |
|---|---|---|
| Phaser | 2Dゲーム用の部品集（キャラ表示、タッチ、音） | 利用者が多く、Claude Code がよく知っている |
| TypeScript | プログラムを書く言語 | 間違いを実行前に見つけやすく、Claude Code が自分で直せる |
| Vite | 手元でゲームを起動する道具 | 保存すると画面がすぐ更新される |
| Git と GitHub | セーブデータ置き場 | 壊れても前の状態に戻せる |
| GitHub Pages | 無料の公開場所 | URLを送るだけで友達がスマホで遊べる |

この構成なら、あとからスマホアプリ化やオンライン対戦を足すこともできます。具体的な方法は、その段階に来たときに Claude Code と相談して決めます。

**設計上の約束**を1つだけ守ります。「ゲームのルール」と「画面の見た目」を別のファイルに分けておくことです。こうしておくと、将来Botを本物のプレイヤーに置き換えるときに、作り直しが少なくて済みます。

**実際の進め方（決定）**：絵は Codex がプログラムで描き直して仕上げる（ファイルは置かない）。BGM も Codex がプログラムで作る。

| 種類 | 対象 | やること |
|---|---|---|
| 絵（洋風の絵本） | タイトル・役の発表・会議・リザルトの枠、ボタン、ふきだし、スタンプ | 紙の質感、手描きの線、やわらかい影。文字は太く読みやすいまま |

| 音 | 会議の BGM | 同じテンポで、少しドキドキする曲 |
| 音 | 勝ち・負けのジングル | リザルトの画面で1回だけ鳴る短い曲 |

決まり：絵の大きさ・足元の位置・当たり判定は変えない（ルールに影響させない）。BGM は先に予約して鳴らし、会議や画面の切りかえで止める・取り消せること。

### M9：エレメントの得意・苦手・不可と更衣室

（遊んでみた感想から追加。本番の「エレメントによって、こなせるミッションが変わる」「着替えて紛れ込む」を、Lite で小さく試す）

- **向き不向き**：ミッションごとに、エレメントによる「得意・苦手・不可」があります。
  - 得意：ミニゲームが短くなる、まちがえにくくなる（Botは早く終わる）。
  - 苦手：ミニゲームが長くなる・難しくなる（Botは時間がかかり、まちがえやすい）。
  - 不可：そのエレメントのままではできない。着替えが必要。
- **釣り（新しいミッション）**：池で魚を釣る。水は得意、火は不可（着替えないとできない）。
- **更衣室**：無垢のパテにエレメントの要素を入れて着替える場所。施設から**ちょっと遠いところ**に置き、「寄り道して着替えるか、苦手なまま進めるか」を選ばせます。
- **着替えのミニゲーム**：リズムに合わせて叩くと早く着替えられます（うまいほど早い）。着替えのあいだは画面が暗くなり、スパイにイタズラされやすくなります。
- 決めること：どのミッションにどのエレメントが得意・苦手・不可か（表にする）。最初のエレメントは何で決まるか。Botがいつ着替えに行くか。

### M10：マップ選びと祠の置き場所・試合の長さ

- **マップ**：数パターンから選びます。ただの四角ではなく、エレメントのエリア（池、火の場所 など）を入れて、毎回マップの感覚が変わるようにします。本番の「自分の国の仕組みやマップを自分で作る楽しみ」につなげます。
- **祠の置き場所（王様の特権）**：試合の最初に、王様が土の祠（お祈りと緊急の呼び出しの場所）を好きな場所に置けます。プレイヤーがスパイのときは、王様Botが置きます。王様にしかできない仕事になり、市民との違いがはっきりします。
- **試合の長さ**：5分版と長い版（仮：10分）を選べます。長い版は、着替えやマップの寄り道をじっくり楽しむ向け。数値は config.ts にまとめます。
- 決めること：マップの数、祠を置ける範囲（ほかの施設に近すぎない など）、長い版の時間とゲージの量。

### M11：スパイのなりすまし

- スパイは、置物にしたパテの姿に着替えて、そのパテに**なりすまし**できます。その場には、置物とは違う**抜け殻**が残ります（「だれかが入れ替わっている」という手がかり）。
- M9 の着替えの仕組みを使います。暴力表現にはせず、抜け殻もポップに見せます。
- 決めること：なりすました相手の仕事の進み具合を引き継ぐか。会議でどの名前に投票すればスパイを当てたことになるか。プレイヤーがなりすまされたときの見せ方（いまは土の精）。Botが抜け殻を見つけたときの疑い方。強さの釣り合い。

### 各段階の終わりにやること

1. **遊ぶ**：自分のスマホで実際に触り、気になった点をそのまま言葉で Claude Code に伝えます。
2. **Codexに点検させる**：下の「Claude Code と Codex の役割分担」の手順でレビューを頼みます。
3. **セーブする**：Claude Code に「ここまでをコミットして、GitHubに送って」と頼みます。

## 設定ファイルの雛形

Claude Code と Codex が同じルールで動くように、共通ルールを「AGENTS.md」に書き、「CLAUDE.md」からそれを読み込ませます。Codex は AGENTS.md を、Claude Code は CLAUDE.md を、作業のたびに自動で読みます。（実物はリポジトリ直下にあります）

## Claude Code と Codex の役割分担

Claude Code が「作る係」、Codex が「点検する係」です。2つに同時に同じファイルを書かせると変更がぶつかるので、書くのは常にどちらか片方だけにします。

| 場面 | 担当 | やり方 |
|---|---|---|
| 機能を作る、直す | Claude Code | 開発ステップの指示文を渡す |
| 段階の終わりの点検 | Codex | 変更内容をレビューさせ、指摘を Claude Code が確かめて直す |
| 作り方そのものへの疑問 | Codex | 「この設計で将来オンライン化できるか」など、批判的に見てもらう |
| バグが直らない | Codex | 原因調査を任せる。直す作業まで任せるときは、その間 Claude Code は触らない |
| 面白いかどうかの判断 | あなた | AIには決められません。遊んで感じたことが正解です |

Claude Code に Codex 用プラグインを入れておくと、Claude Code の画面からそのまま Codex を呼べます。段階の終わりには `/codex:review`、設計への疑問には `/codex:adversarial-review`、バグが直らないときは `/codex:rescue` を使います。初回は `/codex:setup` で準備ができているか確かめます。

### うまく進めるコツ

- **小さく頼む**：1回の依頼は1つのことだけ。「全部作って」は失敗のもとです。
- **見たままを伝える**：「パテが壁をすり抜ける」「音が少し遅れて聞こえる」のように、起きたことをそのまま書けば十分です。画面のスクリーンショットも有効です。
- **こまめにセーブ**：動いている状態でコミットしておけば、壊れても「前のコミットに戻して」で元に戻せます。
- **分からないことは聞く**：「今の変更を中学生にも分かるように説明して」と頼めば、少しずつ仕組みが分かってきます。
- **数値は自分でいじる**：秒数や個数は config.ts にまとまっているので、数字を書き換えるだけで調整できます。最初に自分で触るコードとして最適です。
- **設計図を更新する**：ルールを変えたら docs/design.md も直してもらいます。設計図と実物がずれると、AIが古いルールで作り続けてしまいます。

## 壮大版への道のり

シンプル版が面白いと確かめられたら、『PATERIAL』企画書（最終確定版）の要素を1章ずつ足していきます。順番は「作るのが軽くて、遊びが大きく広がるもの」からです。

| 章 | 足すもの | 最終確定版での対応箇所 | 作る重さ |
|---|---|---|---|
| 第1章 | PATERIAL Lite（この設計図） | コア・ゲームサイクルの一部 | 軽い |
| 第2章 | パーツの着せ替え、4種のポイント、国を3〜4つに | キャラクター、報酬設計 | 軽い |
| 第3章 | 自分の国づくり（1人用）、設計図カケラからのクラフト | 資源の2段構え、設計図クラフト | 中くらい |
| 第4章 | 友達とのオンライン対戦（4〜6人、合言葉で入室） | お祭り合戦のショート戦 | 重い |
| 第5章 | 維持費とおやすみモード、プレイスタイルの3すくみ | ソロ成長のトレードオフ、相性システム | 中くらい |
| 第6章 | 同盟と裏切り、ミドル戦とロング戦、6〜8国 | お祭り合戦の全体 | 重い |

第4章のオンライン化が最大の山です。そこまでに「ルールと画面を分ける」約束を守れていれば、Botを本物のプレイヤーに入れ替える形で進められます。最初は知らない人同士のマッチングではなく、友達同士が合言葉で集まる方式にすると、人が少なくても遊べます。

### 本番に向けたメモ：お祈りはすべての国で共通

お祈りする場所の **外観は国ごとの雰囲気** にします（例：和＝神社風、洋＝教会風、中＝お寺風、南米＝太陽の神殿風）。ただし **中に入ると、どの国も同じ「土の祠」** で、お祈りの作法（土のお祈り）も共通です。宗教の違いは出さず、国ごとの違いは見た目の雰囲気と、パテの色・叩く音・名産・小さな得意（docs/vision.md）で出します。
