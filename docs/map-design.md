# 五つ浜の道しるべ

## 島と道

820 × 870 px の地図に、北から時計回りに火・水・土・風・雷の岬が並ぶ。岬の間は湾にして、スマホの追従カメラで移動中も海岸線と地形から方角を見分けやすくする。

土の祠（呼び出しの鈴）と鳥居がある中央広場から、5本の道が岬へ扇状に伸びる。色付きの地形にぶつかる手前で左右に分かれ、片側は採取場を経てふちを曲がり、反対側は裏手の灯籠を経て奥で合流する。奥の灯籠からは岬の灯籠と出口候補へ進める。広場の外側には環状路があり、隣へ移るときは広場まで戻らずに済む。南の湾には土と風を結ぶ道、西の湾には雷の裏道から茶釜と環状路へ抜ける道がある。

明るい道・橋・広場とゾーン外の陸地は、どの体でも歩ける。色付き地形の中は同じエレメントの体で横切れる。海岸の外は全員通行不可。同じ体はゾーンをまっすぐ抜けて奥へ行ったり、手前のふちから対岸へ渡って採取場を続けて回ったりできる。道にも左右の選択肢があり、共同ミッションで別々の灯籠へ向かいやすい。

| 岬 | ゾーンの輪郭と見た目 | 道・橋 |
| --- | --- | --- |
| 北・火の窯野 | 窯のまわりに広がる朱の炎の野。外へ広がる裾に火の舌を重ねる。 | 東のふちを折れ、奥の石畳を通って西へ回れる。 |
| 東北東・水の青波湖 | 丸く張り出す藍の湖。重なる青海波で水面を表す。 | 湖の外寄りに板橋が1本。橋の中央に奥の灯籠、対岸の橋詰に採取場を置く。 |
| 南東・土の赤岩峡 | くびれのある赤土の峡谷。角張った割れ目と岩の層を重ねる。 | 岩のふちを回り、峡谷の奥を横切る踏み固めた道を通る。 |
| 南西・風のそよぎ丘 | 扇のように膨らんだ若草色の丘。渦や流線、斜めになびく草で突風を表す。 | 丘の脇で曲がり、尾根の風よけ道を通る。 |
| 西北西・雷の紫雲沼 | 先端の尖った藤色の湿原。低い雲と稲妻の模様を重ねる。 | 沼の外寄りに板橋が1本。橋の中央に奥の灯籠、対岸の橋詰に採取場を置く。 |

橋は計2本。どちらもゾーンの奥側を横断するため、違う体は岸に沿って橋詰まで回る。採取場は各ゾーンのふちと対岸に1か所ずつ、スイッチ候補は道沿いに6か所ずつ。6候補から試合で使う地点を選べば、同じエレメントに最大6か所を配れる。地点までの通行と、ミッション操作の相性は別のルールとして扱う。

歯車の櫓は火と水の間、茶釜は風と雷の間の環状路沿い。依代の祠は土と風の間の南の湾に入り、中央から道で約245 px（約2.2秒）。宝物庫候補は火の裏道・水の内側・風の内側に各1か所あり、岬の先端から離れた分岐に置く。出口候補は5つの岬に1か所ずつ。方角を表す `side` に北・東北東・南東・南西・西北西を持たせているので、王様が2つ選ぶときは異なる方角を指定できる。

## 歩く時間

中央広場の中心から、道と橋だけの場合と、対応する体で専用の近道を使う場合を比較した。地図データの経路の長さを 110 px/秒で割った片道の概算。採取・操作・乗りうつりの時間は含めない。

| エリア | 奥の灯籠④ 道と橋 | 奥の灯籠④ 近道 | 岬の灯籠⑥ 道と橋 | 岬の灯籠⑥ 近道 |
| --- | ---: | ---: | ---: | ---: |
| 火 | 434 px / 3.9秒 | 287 px / 2.6秒 | 497 px / 4.5秒 | 342 px / 3.1秒 |
| 水 | 426 px / 3.9秒 | 279 px / 2.5秒 | 490 px / 4.5秒 | 334 px / 3.0秒 |
| 土 | 443 px / 4.0秒 | 297 px / 2.7秒 | 507 px / 4.6秒 | 352 px / 3.2秒 |
| 風 | 421 px / 3.8秒 | 274 px / 2.5秒 | 485 px / 4.4秒 | 329 px / 3.0秒 |
| 雷 | 437 px / 4.0秒 | 291 px / 2.6秒 | 501 px / 4.6秒 | 346 px / 3.1秒 |

奥の灯籠へは、どの岬でも対応する体で約146 px（約1.3秒）短くなる。1回の往復だけで祠へ寄るか、複数の採取・ミッションをまとめるかで、乗りうつりの価値が変わる。

`canWalk` は座標一点の通行判定。`findMapRoute` は道路・橋の中心線と、対応する体だけの近道を結んだグラフ（道のつながり）から最短経路を返す。`roadsOnly` を指定すると専用の近道を外して比較できる。登録地点以外は、直線で安全につながるグラフ上の地点を経由する。表の数値はこの経路上の目安。

## 和の国の絵づくり

生成りの和紙色を道に、藍・朱・弁柄・若草・藤色を地形に使い、墨の輪郭と版を重ねたような濃淡で浮世絵の絵地図に寄せる。火の舌、波、岩の割れ目、風の渦、雷雲という形の違いでも地形を見分けられるようにする。橋は板目、広場は石畳。石灯籠の灯り、鳥居の朱、櫓の歯車、茶釜の丸い輪郭を視線の目印にする。進めない地形の手前では足踏みや戸惑う仕草で示し、パテはそのまま道を選べる。

## 決めきれなかったこと

- 5分の試合で採取と共同ミッションを回したときの近道の価値。乗りうつりの入力時間も含めて試遊し、橋詰や灯籠の位置を調整する。
- 360 × 640 の追従カメラでの道幅、パテ同士のすれ違い、パテの体の幅を含めた当たり判定、地形の進入不可を知らせる演出。
- 宝物庫を海岸からどれだけ離すか、出口2つと宝物庫の組み合わせによる追いかけっこの釣り合い、土の祠を王様が動かせる範囲。
- 30候補から選んだ灯籠だけを本編でどう見せるか。浮世絵の模様の密度と、地形や次の分岐を見せる目印の大きさ。
