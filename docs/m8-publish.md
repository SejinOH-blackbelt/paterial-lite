# M8：公開の手順と確認項目

## しくみ

- `.github/workflows/deploy.yml`（GitHub Actions：GitHub が自動で作業してくれる仕組み）が、main にコミットを送るたびに次を行います。
  1. 部品のインストール（`npm ci`）
  2. 自動テスト（`npm test`）… 1つでも失敗したら、公開しません
  3. 公開用ファイルを作る（`npm run build`）
  4. GitHub Pages（GitHub の無料のサイト公開機能）に置く
- 公開先の URL：https://sejinoh-blackbelt.github.io/paterial-lite/

## 最初の1回だけ、GitHub の画面でやること

1. GitHub で https://github.com/SejinOH-blackbelt/paterial-lite を開く。
2. リポジトリが「Private（非公開）」なら、無料プランでは Pages が使えません。どちらかを選びます。
   - リポジトリを公開する：Settings → 一番下の「Danger Zone」→「Change visibility」→ Public。プログラムも見られるようになります。
   - 有料プラン（GitHub Pro など）にする：プログラムは非公開のまま、遊ぶページだけ公開できます。
3. Settings → 左のメニューの「Pages」→「Build and deployment」の「Source」を **GitHub Actions** にする。
4. 上のタブの「Actions」を開き、「公開（GitHub Pages）」を選んで「Run workflow」を押す（または次にコミットを送ると自動で動く）。
5. 緑のチェックがついたら、公開先の URL を開く。赤い × なら、その画面を見せてください。

## スマホでの確認項目

公開したページを、スマホの縦持ちで開いて確かめます。iPhone（Safari）と Android（Chrome）の両方で見られると安心です。

### 開く・表示
- [ ] URL を開くとタイトル画面が出る（真っ白・真っ黒のままにならない）
- [ ] 縦持ちで、画面の上下左右が切れていない（ノッチや角の丸みで文字が隠れない）
- [ ] 文字がつぶれず読める（あそびかた、ミッション、会議の記録欄）
- [ ] 横向きにしても壊れない（縦に戻せば遊べる）

### 音
- [ ] 「あそぶ」を押したあと、BGM が鳴る（iPhone はマナーモードだと鳴らないことがある）
- [ ] 採取の拍の「カチッ」と BGM の拍がそろっている
- [ ] 叩いた音（ポコッ）が、指が触れた瞬間に鳴る（遅れて聞こえない）
- [ ] 会議で曲が変わり、戻ると採取場の曲に戻る

### 操作
- [ ] スティックで8方向に動ける。親指が届く
- [ ] スティックを倒しながら、もう片方の指で採取ボタンを押せる（複数の指）
- [ ] 採取で連打しても、画面がスクロール・拡大しない
- [ ] 施設のミニゲーム（太鼓・ジグソー・杭むすび・お祈り）が最後までできる
- [ ] 会議で、パテを選ぶ・スタンプ・地図にピン・投票ができる

### 動き
- [ ] 5分の試合を最後まで遊んで、カクつきや止まりがない
- [ ] 途中で別のアプリに切りかえて戻っても、音と判定がずれない
- [ ] 「もう1回」で2試合目も遊べる

### 友達に送る
- [ ] URL を LINE などで送って、相手のスマホで開ける
- [ ] 相手が説明なしで「あそびかた」を読んで遊び始められる

## 気づいたことの伝え方

「どの端末（例：iPhone 13、iOS 17）」「どの画面」「何をしたら」「どうなった」を書いて、Claude Code に伝えてください。画面写真があると早く直せます。
