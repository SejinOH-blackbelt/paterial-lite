# PATERIAL 全体設計図（本番版）

Nov 25, 2026 ・ @Sejin Oh

> このファイルは本番版『PATERIAL』の全体像です。今作っている PATERIAL Lite（docs/design.md）は、このうち「スパイ的な侵略」の1場面を切り出したものです。Lite を作るときに迷ったら、ここに書かれた世界観とつながるほうを選びます。

## 全体像

PATERIALは、8つの国から1つを選んで素材を集め、自分の国を育てながら、フレンドの国へ「戦争的」か「スパイ的」に侵略するオンラインの箱庭ゲームです。戦いは直接描かず、リズムゲームの結果で勝敗が決まります。

**コンセプト**：「誰も死なない、誰でも主役。コツコツ育てた国で、混ぜて騙し合うポップな箱庭オンライン」

- **脱・暴力**：侵略は「相手を自分のファンにする」「陣地を自分の色に塗り替える」というポップな表現だけで描きます。
- **常時参加**：やられて画面を見ているだけの時間を作りません。脱落はなく、初心者でも最後まで勝敗に関われます。
- **失うものが小さい**：侵略されても建物は壊れず、資源も大きく減りません。負けてもコミカルな不調で済みます。
- **最強を固定しない**：国が大きくなるほど維持費と入り込まれやすさが増え、相性で有利不利も入れ替わります。

### 遊びの循環

1. **国を選ぶ**：初回に8つの国から好きな1つを選びます。
2. **素材を集める**：山・川・海のフィールドで、リズム採取をして基本素材を集めます。ソロでも協力でもできます。
3. **国を育てる**：建物を建て、防犯トラップを置き、アイテムをクラフトします。維持費も払います。
4. **侵略する／守る**：フレンドの国へ、戦争的かスパイ的かを選んで侵略します。自分の国もいつ侵略されるか分かりません。
5. **手に入れたもので、さらに育てる**：侵略で得た他国の名産や設計図で、「ご当地ミックスの建物」を建てます。ここから 2 に戻ります。

対応プラットフォームはスマホが基本で、PCとのクロスプレイに対応します。1回の侵略や合戦は5〜10分、友達同士のロング戦は最大30分です。

## パテと8つの国

全プレイヤーが同じハニワ型の「パテ」を使い、国ごとの違いは体の色と、ごく小さな得意だけです。形が同じなので、体を塗り替えれば他国に紛れ込めます。

### パテ

- 素焼きの土っぽいひび割れがある、丸っこいハニワ。眉毛はなく、空洞の目と口、短い手足。性別はありません。
- 集めたパーツを体に「ブスッと刺して」飾れます。
- 中が空洞なので、叩くと素材ごとに違う音が鳴ります。この音がリズムゲームの楽器になり、スパイを見破る手がかりにもなります。
- 表情はいつも「ポカーン」。何を考えているか分からないのが、スパイの駆け引きに合います。
- **エレメント（仮）**：パテは1体ずつ、火・水・土・風などのエレメントを持ちます。ハニワは土をこね（水）、焼いて（火）生まれるので、パテの生まれとつながります。体に小さな炎・しずく・苔と小石・つむじ風などの飾りが付き、見ただけで分かります。国（体の色）とは別で、同じ国にいろいろなエレメントのパテがいます。
  - 案：基本の4つ（火・水・土・風）と、その上位の4つ（火→マグマ、水→氷、風→雷、土→岩）で8つ。上位は育てると変わる、などの使い方を考える。
  - Lite のデザイン（docs/concept/element-pates.png）：火・水・土・風・雷の5つ。エレメントで体の色も変わる（火はオレンジと焦げ茶、水は水色、風は白、雷は紺）。
  - 決めること：国の違いは「体の色」なので、エレメントで体の色が変わると、国の色をどこで見せるか（足、模様、頭のパーツの色など）を決める必要がある。スパイが「相手の国の色に塗る」仕組みともつながる。
  - まずは見た目だけ。相性やミニゲームへの効き方は、あとで決めます。

### 8つの国

名産と叩く音のうち、企画書にないものは仮です。

| 国 | パテの色（素材） | 叩く音 | 名産（ご当地エッセンス） | 小さな得意 | 向きのスタイル |
|---|---|---|---|---|---|
| 和 | 茶色の素焼き | ポコッ | からくり歯車 | クラフトの品質が高い | バランス |
| 洋 | 白い陶器 | カーン | 音符クリスタル | リズムバトルの盛り上がり | エンタメ |
| 中 | 橙黄色 | チーン | 量産レンガ | 大量生産。たまにエラー品 | エンタメ |
| 南米 | 赤土 | ドンッ | 太陽の羽根 | 協力タッグで味方を盛り上げる | エンタメ |
| バイキング | グレーの石 | コツッ | 溶けない氷 | 遠征が得意 | 潜入 |
| アラビアン | 砂色 | サラッ | 蛇の砂時計 | 維持費が安い | 潜入 |
| アトランティス | 光る青 | ポチャン | 深海の真珠 | 防犯トラップが強い | 防犯 |
| スチームパンク | 暗い鉄 | ガイン | 雷のコイル | クラフトが速い | 防犯 |

「向きのスタイル」は最初の得意にすぎません。どの国でも、建物やアイテム次第で潜入・エンタメ・防犯のどれにでも尖らせられます。

### 国を選ぶとき

- 初回に1つ選びます。後から変えられるかは未定です。
- 同じ国を選んだプレイヤーは大勢いても構いません。国は「種族」のようなもので、一人ひとりがその国の形式で自分の国を持ちます。

## 資源と国づくり

資源は、どこでも採れる「基本素材」と、各国にしかない「ご当地エッセンス」の2段構えです。他国の名産が欲しいことが、侵略に出かけるいちばんの理由になります。

| 資源 | 例 | 入手場所 | 使い道 |
|---|---|---|---|
| 基本素材 | 鉱石、木材、粘土、サンゴ | 山・川・海のフィールド | 国の拡大、基本の建物、維持費 |
| ご当地エッセンス | からくり歯車、溶けない氷 | 自国で生産／侵略で他国から入手 | 潜入・防犯アイテム、ご当地ミックスの建物 |
| 設計図のカケラ | 「雪化粧温泉旅館」のカケラ | スパイで他国の設備をスキャン | 集めきるとその建物を自国でクラフトできる |

### 国を育てると得られるものと、引き換えに生まれるもの

| 得られるもの | 引き換えに生まれるもの |
|---|---|
| 置ける建物やトラップが増え、街が豪華になる | 街が広く住民が多いほど、スパイが紛れ込みやすい |
| 自国の生産効率が上がる | 大きい国ほど、毎日の維持費が高い |
| 新しいアイテムが作れ、侵略の手札が増える | 名産が豊富なほど、他国に狙われやすい |

### 維持費が足りないとき

建物は壊れず、消えもしません。その代わり、国がコミカルな不調になります。

- **おやすみモード**：防犯トラップが「Zzz」と居眠りして動かなくなります。スパイが入り放題になります。
- **置物化**：住民のパテがただの土の置物になってホコリを被り、生産が止まり、リズムバトルも弱くなります。
- **休止スイッチ**：しばらく遊べないときは、豪華な施設を手動で休止して維持費をゼロにできます。

この仕組みで、遊ぶ時間が長い人が独走しにくくなり、小さく強い国という選択肢も成り立ちます。

## 侵略

フレンドの国へはいつでも侵略でき、そのたびに「戦争的」か「スパイ的」かを選びます。戦争的は正面からリズムで勝負して陣地を塗り替え、スパイ的はこっそり忍び込んで名産と設計図を持ち帰ります。

| | 戦争的な侵略（お祭り合戦） | スパイ的な侵略（潜入） |
|---|---|---|
| やること | 相性のある部隊を組んで乗り込み、ぶつかるたびにリズムのミニゲームで勝負して、相手の陣地を自分の色に塗り替える | 体を相手国の色に塗った代表パテ1体で忍び込み、住民に紛れる |
| 目的 | 相手の住民を自分のファンにする、陣地を塗る | 名産のコピー、設計図のカケラのスキャン、イタズラを仕掛ける |
| 得られるもの | 基本素材と、塗った陣地からの「ファンの差し入れ」 | ご当地エッセンス、設計図のカケラ |
| 相手の損 | 塗られた陣地はしばらく生産が少し落ちる。時間がたつと元の色に戻る | ほぼなし。コピーされても名産も設備も減らない |
| 得意な人 | リズムゲームが好きな人 | 観察と駆け引きが好きな人 |

### 戦争的な侵略：部隊とリズムで勝負する

戦いそのものは描きません。広場を挙げた「お祭り」として見せ、両国のパテが自分の体を叩いて演奏することで勝敗が決まります。

1. **部隊を組む**：自国のパテで部隊を組みます。部隊は3種類あり、じゃんけんのような相性があります。
2. **進軍する**：相手の国の広場をめがけて部隊を進めます。守る側も部隊を置いて迎え撃ちます。
3. **ぶつかる**：部隊同士がぶつかるとミニゲームが始まります。ミニゲームは4種類から毎回入れ替わります。
4. **相性はボーナスで効く**：相性で有利な部隊は、判定が甘くなる、持ち時間が長くなるなどのボーナスをもらいます。不利でも腕前で逆転できます。
5. **陣地を塗る**：ミニゲームに勝った部隊は、その広場を自分の色に塗ります。制限時間が来たとき、塗った広場が多い方の勝ちです。負けても脱落はなく、塗られた広場も時間で元の色に戻ります。

建物やアイテムは「ミニゲームへの介入」として効きます。例：守る側の太鼓櫓が攻める側の拍をずらす。攻める側のダンススピーカーが判定を甘くする。

#### 部隊の相性（仮）

| 部隊 | 強い相手 | 理由 |
|---|---|---|
| 太鼓隊 | 笛隊 | 大きな音で笛の音色をかき消す |
| 笛隊 | 踊り隊 | 笛の音で踊りを操る |
| 踊り隊 | 太鼓隊 | ノリで太鼓隊まで踊りに巻き込む |

#### ぶつかったときのミニゲーム

| ミニゲーム | 遊び方 | 得意な人 |
|---|---|---|
| リズムタップ | ぶつかった瞬間から4拍、体を叩いて「ポコポコ」と鳴らす。拍に合うほど高得点 | リズム感のある人 |
| 無音カウント | BGMの途中で音が消え、頭の中で拍を数えて8拍目でボタンを押す。ぴったりに近いほど高得点。数回くり返して合計で勝負 | 体内時計が正確な人 |
| まねっこ太鼓 | 4つのボタン（頭・お腹・右手・左手。それぞれ違う音）を使う。攻める側が順番に押し、守る側が同じボタンを同じ順番で押せれば守り成功。攻守を交代し、成功するたびに1つずつ長くなる。リズムまで合えばボーナス | 記憶力のいい人 |
| 押し合い連打 | 連打して、陣地のメーターを相手側へ押し込む。綱引きのような勝負 | 根性のある人 |

どのミニゲームも、採点はそれぞれの端末の中で行い、点数だけを送り合います。通信の遅れで「押したのにズレた」とならないようにするためです。

### スパイ的な侵略：紛れて、持ち帰る

PATERIAL Lite で作る遊びが、この侵略の原型です。

- 出発前に、代表パテを相手国の色に塗り替えます。塗りは時間とともに剥がれ、塗りムラや叩く音の違いで正体がバレやすくなります。
- 相手国の住民に紛れて採取を手伝いながら、名産のコピーや設備のスキャンを狙います。
- イタズラとして、防犯トラップの解除や、偽物とのすり替えもできます。
- 住民に正体を見破られたら、「てへぺろ」で強制送還され、その回に集めたものの一部を失います。
- **寝返り（亡命）**：スパイは住民にこっそり近づき、自分の国へ寝返らせることもできます。成功すると、その住民は仕事をやめて国境へ「亡命」します。失敗すると、相手が「あやしい！」と声を上げ、まわりに聞こえてスパイだと疑われやすくなります。（Lite では作らず、イタズラ「置物にする」だけにする）
- **王様の支持度**：守る側の王様（プレイヤー）は、ぬれぎぬで住民を疑うと支持度が下がります。下がりすぎると住民がストライキ（仕事をやめて座り込み、プラカードを掲げる）を起こします。暴力表現にはしません。

### 侵略できるタイミング

相手がオンラインのときは、いつでも侵略できます。オフラインのときは、相手が自分で決めた「開国時間」の間だけ侵略できます。

- **開国時間**：1日のうち、侵略を受け付ける時間帯を自分で選びます。最低2時間（仮）で、寝ている時間でも構いません。
- **開国ボーナス**：開国中は観光客が訪れ、生産が増えて、おもてなしポイントも貯まります。開けるほど得をするので、誰も開国しない状態を防げます。
- **予告状**：攻める側は「今夜8時に行きます」と予告状を送れます。受けた側は、オンラインで迎え撃つか、Botに任せるかを選びます。
- **留守中の守り**：戦争的な侵略にはBotの部隊、スパイ的な侵略には住民Botが対応します。強さは、その国の建物、トラップ、維持費の状態で決まります。
- **リプレイ**：ログインしたら、留守中の侵略をリプレイで見られます。「誰がいつ何をしたか」が分かるので、やり返す動機になります。
- **保護時間**：侵略されたあとしばらくは、同じ国への侵略を休みます。狙われ続けないようにするためです。

## みんなで同時に遊ぶとき

フレンドが同時につながっているときは、協力タッグを組んで他の国を攻められます。ただしタッグの中に、攻めるふりをしながら味方を裏切るスパイがいるかもしれません。

### 協力タッグ

- 2〜4人でタッグを組み、他の国へ一緒に侵略します。戦争的なら合奏になり、リズムがそろうほど効果が上がります。
- 守る側も、つながっているフレンドを助っ人として呼べます。
- 1対1から6〜8国が入り乱れる戦いまで対応します。

| 試合の長さ | 遊びの中心 | 主な報酬 |
|---|---|---|
| ショート（5分） | ノリと勢いのパーティ戦 | 基本素材とポイント |
| ミドル（10分） | 相性の読み合いと、同盟・裏切り | 他国のご当地エッセンス |
| ロング（20〜30分） | 友達同士でじっくり外交と要塞化 | 超レアな設計図 |

### 裏切り

- タッグの中の1人が、こっそり「裏切り役」を選べます。味方には分かりません。
- 裏切り役は、味方のリズムをこっそりずらす、助っ人のふりをして味方のトラップを解除する、などができます。
- 「友好のプレゼント」も贈れます。中に自分の国の旗や、強制ダンススピーカーが仕込まれた「トロイの木馬」です。
- 試合の終わりに「会議」があり、スタンプとジェスチャーで裏切り者を推理して投票します。文字チャットは使いません。
- 裏切りがバレても、クラッカーと「てへぺろスタンプ」でコミカルに演出し、ギスギスしないようにします。

### 相性

**プレイスタイルの3すくみ**：潜入特化 ＞ エンタメ特化 ＞ 防犯特化 ＞ 潜入特化。尖るほど有利な相手を圧倒できますが、不利な相手には脆くなります。

**国同士の「敵だと◎・味方だと×」**：敵として戦うときの有利不利とは別に、タッグを組んだときの相性もあります。例：和の丁寧なリズムを中のエラー品がうっかり邪魔する。洋と南米が組むとテンションが爆上がりする。「誰と組み、いつ裏切るか」が毎回変わります。

## 報酬と続ける理由

勝ち負けだけでなく、遊び方ごとにポイントがもらえます。ポイントは、限定パーツ、称号、設計図と交換できます。

| ポイント | もらえるとき |
|---|---|
| スリルポイント | バレずに潜入し、設計図のカケラをスキャンできた |
| 名探偵ポイント | スパイや裏切り者を見破った、トラップに引っかけた |
| ノリノリポイント | リズムバトルや採取で場を盛り上げた |
| おもてなしポイント | 多くのプレイヤーが遊びに来た、街づくりで「いいね」をもらった |

続けて遊ぶ理由は、次の3つで作ります。

- **自分の国が育つ楽しさ**：他国の名産を混ぜた「ご当地ミックスの建物」で、自分だけの街になっていきます。
- **フレンドとのやりとり**：留守中の侵略をリプレイで見てやり返す、という繰り返しが生まれます。
- **毎回変わる駆け引き**：相性と裏切りがあるので、同じメンバーでも展開が毎回違います。

## Liteとの関係と作る順番

PATERIAL Lite は、本番の「スパイ的な侵略」の1場面を切り出したものです。バイキングの国が、和の国へ代表パテを送り込んだ場面だと考えると、そのままつながります。

| Liteでの名前 | 本番での意味 |
|---|---|
| 採取場 | 和の国の中の一区画 |
| 市民と市民Bot | 和の国の住民。オンライン版では、守りに来たフレンドが入ることもある |
| スパイ | バイキングの国から送り込まれた代表パテ |
| 維持費の納品 | 本番の国づくりの維持費の簡易版 |
| 名物のスキャン | 設計図のカケラ集め |
| 会議と投票 | 裏切り者を探す会議の原型 |

### 作る順番

各章で遊んで面白さを確かめてから、次に進みます。

1. **第1章：PATERIAL Lite**：スパイ的な侵略の1場面。1人 + Bot。別の「開発設計図（Claude Code版）」で作ります。
2. **第2章：戦争的な侵略の試作**：リズムバトルで広場を塗り合う遊びを、Bot相手で作ります。
3. **第3章：自分の国づくり**：素材、建物、維持費、クラフトを足して、1人で育てられるようにします。国は3〜4つ。
4. **第4章：フレンドへの侵略（非同期）**：フレンドの国のデータを送り合い、留守中の国に侵略できるようにします。サーバーが必要になる最初の章です。
5. **第5章：同時プレイ**：協力タッグと裏切りを、友達同士の合言葉で遊べるようにします。いちばん難しい章です。
6. **第6章：全部入り**：8国、相性、ミドル・ロング戦、スマホアプリ化。

第4章より前に「待たずに遊べる非同期」を置いているのは、人が少なくても成り立つからです。同時につながる遊びは、遊ぶ人が増えてからでも間に合います。
