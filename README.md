# PATERIAL Lite

ハニワ・スパイ・リズムゲーム（1人 + Bot 5体）。設計図は [docs/design.md](docs/design.md)。

## 動かし方

```bash
npm install     # 必要な部品をダウンロード（最初の1回だけ）
npm run dev     # 開発用サーバーを起動 → 表示された URL をブラウザで開く
npm run build   # 型チェック（間違い探し）＋公開用ファイルを dist/ に作る
npm test        # 自動テスト
```
